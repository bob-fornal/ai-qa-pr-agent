Five skills, one source of truth

SkillWhat it holds
pr-qa-reviewThe entry point. Runs the pipeline, checks the result, saves the report
pr-change-analysisHow to get the diff, sort changes into 13 categories, trace callers
critical-path-identification15 high-risk categories, scoring scales, P0 to P3 thresholds

All five live in .claude/skills/. Claude Code and Copilot both read that folder, so the rules exist in one place.

11:00 to 12:30. Skills are Markdown files with a short description that tells the AI when to load them. Four hold knowledge, one orchestrates. The important design decision: the rules live in skills, not in agent prompts. Agents are thin wrappers that say which skills to follow. Copilot in VS Code and the Copilot coding agent read .claude/skills too, so a change to the scoring rubric reaches both tools at once.
