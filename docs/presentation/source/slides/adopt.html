Adopting it in your repo

1

Copy .claude/, .github/agents/ and .github/prompts/ into the repository

2

Install and authenticate the GitHub CLI so the agents can read PRs by number

3

Run it on five recent merged PRs and compare with what QA actually tested

4

Tune the high-risk categories and thresholds to your domain

5

Optionally run headless in CI: claude -p "/pr-qa-review 482 --save"
