How it works: a four-stage pipeline

1 · ANALYZE

Change map

Diff, categories, callers, entry points, existing tests

2 · RANK

Critical paths

Flows, not files. Impact × likelihood gives P0 to P3

3 · DECIDE

Test types

Manual, Smoke and/or Automated, each with a reason

4 · REPORT

Fixed format

Same sections every time, in Claude or Copilot

Claude Code: stage 1 and stages 2–3 run as separate subagents, so each starts with a clean context.

Copilot: one custom agent runs all four stages from the same skill files.
